# MOW 博客 — 图片生成提示词 v2.1

> 3 风格 × 2 主题 = 6 张完整场景 · 三段式格式（适配 nano banana 2 深度思考）
> 2026-07-09 先知撰写 · v2.1 格式重构

---

## 使用方法

每段提示词是完整的、复制即用的。直接粘贴到 nano banana 2 输入框，一次性发送。

三段结构对应深度思考模型的推理层次：
- **【风格指令】** → 抽象层：先理解"这是一个什么世界"
- **【构图指令】** → 空间层：再规划"画面里有什么、在哪"
- **【技术指令】** → 执行层：最后执行"怎么画、不能画什么"

---

## 通过 / 重来 通用检查表

### ✅ 通过

- 有明确主光源方向，阴影一致
- 色彩不发灰、不发荧光、不发紫
- 地平线约在画面 35-45% 高度（白天）/ 窗户在画面上部约 25-40% 位置（夜晚）
- 牧羊人为背影/侧影，体型正常
- 边牧的黑白色分布清晰（白胸、白吻、四足白）
- 无 AI 常见瑕疵：多余手指、融合物体、不自然接缝

### ❌ 重来

- 光源混乱，阴影往不同方向
- 人形崩坏（手指粘连、比例失调、脸部扭曲）
- 狗不像边牧（颜色分布错）或与人体型比例严重失调
- 构图崩溃（地平线歪斜、所有元素挤在一角）
- 风格不对（日漫风生成写实照片、绝区零风生成软萌赛璐璐等）

### 单张判断流程

```
拿到图 →
  ① 风格对不对？→ 不对：重来 / 对：继续
  ② 光对不对？→ 不对：重来 / 对：继续
  ③ 构图对不对？→ 不对：重来 / 对：继续
  ④ 人和狗对不对？→ 不对：重来 / 对：继续
  ⑤ 细看瑕疵 → ✅ 通过 or 记录瑕疵
```

## 生成策略（40 次怎么用）

```
Phase 1: 日漫风（最确定，先做）
  白天 1-3 次 → 通过后进入夜晚
  夜晚 1-3 次

Phase 2: 雨雾之都风
  白天 1-3 次
  夜晚 1-3 次

Phase 3: 绝区零风（最难）
  白天 1-4 次
  夜晚 1-4 次

最坏消费：20 次。剩余 20 次用于重试和前景元素。
```

**原则**：一张一张来，不同时生成两个主题。同一风格的白天过了，把结构套给夜晚。

# 风格一：日漫风

> 吉卜力 × 新海诚 · 柔和水彩 · 暖调通透 · Bloom 柔光

---

## 1-1 白天：「草地牧羊人」

```
【风格指令】
日系动画电影背景美术风格。柔和但有层次的水彩/赛璐璐质感。
轮廓线温和不锐利。色彩温暖通透，像透过一层薄薄的晨光看到的景色。
光感是核心——高光区域有轻微的过曝柔光（新海诚式 bloom），暗部保留暖色而非死黑。
整体氛围宁静、有呼吸感、像动画电影的一帧截图。

【构图指令】
一片广阔起伏的绿色丘陵草原，从画面底部延伸到远方地平线。
地平线设在画面约 40% 高度处。一条泥土小径从左下角蜿蜒伸向远方。
画面中央偏右的小丘顶上，一个年轻牧羊人背对镜头坐着，望向远方。
牧羊人穿米色宽松亚麻衬衫、深棕色裤子，一顶草帽放在身旁地上。
一只边境牧羊犬（黑白毛色，白胸脯、白色从嘴延伸到额头、四足白色）安静趴在牧羊人身边，耳朵微竖，望向同一方向。
几只白羊散布在周围山坡上安静吃草。
远处地平线上有极淡的蓝色远山轮廓。
天空是柔和的蓝色，几朵蓬松白云从左上向右下铺展，云朵边缘有微弱的金色 rim light。
画面底部生长着野花（白色雏菊、小黄花）和高低错落的长草。
晨光从画面右上方斜照，在草地向阳面形成温暖的金绿色高光。

【技术指令】
色调方案：温暖通透。草绿、土黄、天蓝、奶白云色。
比例：16:9。
禁止：3D 渲染质感、写实照片风格、过度锐利的轮廓线、阴天灰调、赛璐璐动画的硬切阴影。
```

## 1-2 夜晚：「木屋暖灯」

```
【风格指令】
日系动画电影背景美术风格。柔和但有层次的水彩/赛璐璐质感。
轮廓线温和不锐利。色彩温暖通透。高光有轻微 bloom 柔光，暗部保留暖色不死黑。
整体氛围宁静、有呼吸感、像动画电影的一帧截图。
本次场景参考吉卜力室内美术（《哈尔的移动城堡》《魔女宅急便》的房间）：
柔和暖光、生活化细节、木头和织物的温润质感。

【构图指令】
一间日式小木屋内部。画面中上方是一扇敞开的木质格子窗。
透过窗户可以看到：深蓝夜空、一轮满月挂在右上角带着柔光晕、几颗稀疏的银色星星。
窗台上放着一只素色陶土花盆，里面几株郁金香正在盛开——橘粉色和奶油白色，花瓣在月光下微微透亮。
窗户开约三分之一，薄纱窗帘在微风中轻轻飘动。
室内：浅色木地板（有榻榻米质感）。天花板垂下一盏暖黄色纸灯笼，发出柔和的暖光。
画面右侧，年轻牧羊人盘腿坐在深蓝色软垫上，怀抱一把黑色木吉他轻轻弹奏。
吉他共鸣箱上有手绘的红色玫瑰图案（暗红和鲜红）。
牧羊人穿宽松米白色棉质家居服，表情宁静、眼睛微闭，沉浸在音乐中。
牧羊人身旁，一只边境牧羊犬（黑白毛色，白胸白吻）蜷缩在米色毯子上安静睡觉。
左侧有一面浅色木质书架，摆着几本书和小摆件。角落一张小矮桌上放着一杯冒着热气的茶。
光线设计：灯笼的暖黄光（主光源）+ 从窗口泻入的蓝白月光（次要光源），两种光在木地板上柔和交融。

【技术指令】
色调方案：暖琥珀 + 深棕木色 vs 窗外冷蓝 + 银白月光。
比例：16:9。
禁止：冷色调主导整个画面、空旷无生活气息、3D 渲染质感、赛璐璐硬切阴影。
```

# 风格二：雨雾之都风

> Varsapura "2.5D" · 写实环境 + 二次元角色 · 湿润大气 · 灰蓝克制

---

## 2-1 白天：「草地牧羊人」— 晨雾草原

```
【风格指令】
米哈游《雨雾之都》(Varsapura) 的 "2.5 次元" 美术风格。
自然环境采用写实渲染——光影、材质、大气效果都偏向真实。角色脸部保持二次元动漫风格。
核心视觉元素：湿润大气感、薄雾、地面反光、克制优雅的灰蓝色调。
光影处理偏写实——不是卡通渲染的硬切阴影，而是柔和渐变的 ambient occlusion + 微弱的边缘光。
色彩饱和度整体偏低，接近电影调色——暗部偏冷灰，亮部保留暖色但不刺眼。
整体氛围像雨后初晴或薄雾未散的宁静时刻。

【构图指令】
一片广阔起伏的绿色丘陵草原，但色彩偏克制——草绿中带灰调，不是鲜亮卡通绿。
清晨薄雾在地表低洼处弥漫成薄薄的白纱。湿润的草叶上有微弱的露珠反光（写实细节）。
一条泥土小径因雾气而略显湿润，从左下角延伸向远方。
地平线约在画面 42% 高度，因大气雾气而略微柔化。
画面中央偏右的小丘顶上，年轻牧羊人背对镜头坐着。
角色保持二次元风格（柔和脸部轮廓、动漫比例的五官），但衣物有写实质感——米色亚麻衬衫的褶皱纹理、深棕裤子的布料质感可辨。
身边一只边境牧羊犬（黑白毛色，白胸白吻），毛发有层次感而非平面色块。
几只白羊散布山坡。天空是淡蓝灰色，薄而均匀的云层覆盖（不是块状白云）。
太阳在云层后形成柔和的 diffuse 散射光，方向来自右上方。
整体色调：灰绿、灰蓝、暖灰、土色——克制、优雅、有空气感。

【技术指令】
色调方案：低饱和克制。灰绿 + 灰蓝 + 暖灰 + 土棕。
渲染倾向：写实环境（光影/雾气/水珠） + 二次元角色脸部。
比例：16:9。
禁止：鲜亮饱和色、卡通渲染硬阴影、纯蓝天、块状白云、赛璐璐动画质感。
```

## 2-2 夜晚：「木屋暖灯」— 雨夜木屋

```
【风格指令】
米哈游《雨雾之都》(Varsapura) 的 "2.5 次元" 美术风格。
自然环境采用写实渲染，角色脸部保持二次元动漫风格。
核心视觉元素：湿润大气感、雨丝、水珠、克制优雅的冷暖对比。
光影处理偏写实——柔和的 ambient occlusion 渐变，不是硬切阴影。
色彩饱和度整体偏低，接近电影调色。
本次场景：窗外是细雨蒙蒙的夜晚，室内是单一暖灯的庇护所。

【构图指令】
日式小木屋内部，渲染偏写实——木地板的纹理和微弱反光、织物褶皱、
灯笼纸张的半透明质感都有写实细节。
画面中上方的木质格子窗外，是细雨蒙蒙的夜景：深灰蓝天空，雨丝斜落（可见的细白线），
远处针叶林轮廓在雨雾中模糊，没有星星也没有月亮。
窗户玻璃上有细微的水珠和雨痕。窗台上素色陶土花盆里的郁金香（橘粉和奶油白），花瓣上沾着细密水珠。
室内：暖黄色纸灯笼是唯一主光源，在木地板和家具上投下柔和的暖光，
灯笼光在潮湿空气中微微扩散形成柔光晕。
画面右侧，牧羊人盘腿坐在深蓝软垫上，怀抱一把黑色木吉他轻轻弹奏。
吉他共鸣箱上有手绘红玫瑰图案。牧羊人穿米白棉质家居服，表情宁静，眼睛微闭。
牧羊人身旁，一只边境牧羊犬（黑白毛色，白胸白吻）蜷在米色毯子上安静睡觉。
左侧书架，角落矮桌上一杯热茶冒着蒸汽——蒸汽在空气中形成微小水雾。
光线：单一暖黄主光源（灯笼）。窗外进入的不是月光，而是极淡的雨夜环境光（冷灰蓝），在室内形成微妙的冷暖对比。

【技术指令】
色调方案：暖琥珀 + 深棕木色（室内主体） vs 冷灰蓝 + 雨雾灰（窗外）。
渲染倾向：写实环境质感 + 二次元角色脸部。
比例：16:9。
禁止：晴朗夜空/月亮/星星、鲜亮色彩、卡通渲染平面感、强月光。
```

# 风格三：绝区零风

> Zenless Zone Zero 插画风 · 粗犷轮廓 · 多层阴影 · 高饱和撞色 · 专辑封面感

---

## 3-1 白天：「草地牧羊人」— 插画风草原

```
【风格指令】
《绝区零》(Zenless Zone Zero) 的插画风渲染风格。
这不是传统日漫赛璐璐，也不是写实渲染。核心特征：
(1) 粗犷有力的轮廓线——不是细线，是有笔触感的硬线条，像钢笔或板绘硬笔触；
(2) 多层阴影——至少 2 层暗部层次 + 1 层亮部 + 边缘光（rim light），阴影不是模糊过渡而是有明确形状；
(3) 高饱和撞色——色彩比普通日漫更浓烈、更有"插画感"；
(4) 材质有手办/橡胶的 Q 弹质感——高光和反射区域有光泽；
(5) 画面有"设计感"——不是自然抓拍，而像一张专辑封面或游戏概念插画。
有力量感的美，不是软萌甜。

【构图指令】
一片起伏的绿色丘陵草原，但每座丘陵的轮廓线清晰有力。
草的阴影层次丰富——向阳面是明亮的黄绿，背光面是深沉的墨绿，中间有一层中间调。
地平线约在画面 40% 高度，以一道粗犷的线条分割天地。
一条泥土小径从左下角蜿蜒向远方，路面有清晰的笔触纹理质感。
画面中央偏右的小丘顶上，牧羊人背对镜头坐着——角色轮廓线粗犷有力（绝区零式硬线稿），
米色衬衫有多层褶皱阴影，深棕裤子。
牧羊人身边，一只边境牧羊犬趴着，毛色黑白分明——白色部分接近纯白，黑色部分深黑，
身体边缘有金色 rim light 勾勒轮廓。几只白羊散布山坡。
天空是浓郁的蓝色，白云有明确的形状边缘——不像日漫风的柔和云朵，更像插画中的设计化几何云。
阳光从右上方来，光照区域的草叶边缘有金色 rim light 描边。
整体像一张高质量的游戏概念插画或 CD 封面。

【技术指令】
色调方案：高饱和。浓郁草绿（明黄绿 + 墨绿）+ 深沉土棕 + 张力蓝 + 纯白 + 金色 rim light。
轮廓：粗犷有力，有笔触感。
阴影：多层明确分界（2层暗部 + 1层亮部 + 边缘光）。
比例：16:9。
禁止：柔和模糊轮廓、低饱和度、水彩质感、吉卜力式软萌、柔和渐变阴影。
```

## 3-2 夜晚：「木屋暖灯」— 插画风室内

```
【风格指令】
《绝区零》(Zenless Zone Zero) 的插画风渲染风格。
核心特征：(1) 粗犷有力的轮廓线——有笔触感的硬线条；
(2) 多层阴影——至少 2 层暗部 + 1 层亮部 + 边缘光，阴影有明确形状边界；
(3) 高饱和撞色——暖色（琥珀/橘/深棕）与冷色（窗外深蓝夜空）形成强烈对比；
(4) 材质有手办橡胶 Q 弹光泽——尤其是高光和反射区域；
(5) 画面有"设计感"——像专辑封面或游戏概念插画。
有力量感的温馨，不是软绵绵的甜。

【构图指令】
日式小木屋内部。画面中上方的木质格子窗——窗框线条粗犷笔直，有笔触感。
窗外是深蓝到近乎墨色的夜空，一轮明亮的满月（右上角）带着明确的 rim light 光晕，
几颗大而明亮的星星（不是日漫风的小星点，更像设计化的星芒图案）。
窗台上陶土花盆里的郁金香盛开——橘粉和奶油白的花色比现实更浓郁饱满。
室内：浅色木地板但阴影层次分明——灯笼光照射区域是暖橘色，阴影区域是深棕近乎黑，
明暗之间分界清晰（不是柔和过渡，是明确色块——绝区零标志特征）。
天花板垂下的暖黄纸灯笼——高光部分接近白色（有反射光泽），暗部是浓郁的橘色。
画面右侧，牧羊人盘腿弹黑色木吉他——吉他的黑色有暗部层次和反光高光（手办般的橡胶质感），
玫瑰图案用暗红+鲜红撞色绘制。牧羊人衣服有明确的褶皱阴影层。
边牧犬蜷在毯子上——毯子褶皱有多层阴影，体积感强烈。
左侧书架，矮桌上一杯茶冒蒸汽——蒸汽的白色涡旋有清晰的轮廓线。
光线：灯笼的强烈暖黄光（主导） vs 窗口进来的锐利蓝白月光（第二光源），
两道光在地板上形成清晰的明暗交界线——不是柔和过渡，是明确的色块分界。

【技术指令】
色调方案：高饱和撞色。暖琥珀 + 深棕 + 橘（室内主体） vs 墨蓝 + 亮白月光（窗外）。
轮廓：粗犷有力，有笔触感。
阴影：多层明确分界，不是柔和渐变。
比例：16:9。
禁止：柔和过渡阴影、低饱和度、吉卜力软萌、写实渲染、赛璐璐动画的单一暗部。
```

# 附录 A：常见翻车场景 & 补救方案

| 翻车现象 | 可能原因 | 补救：在原提示词末尾追加 |
|----------|---------|------------------------|
| 日漫风变写实照片 | "水彩质感"没有被理解 | 追加："这不是照片。这是手绘动画背景。用画笔画的，不是相机拍的。" |
| 夜晚双光源变灰光 | AI 把两种光平均化了 | 改为："主光源只有灯笼暖黄光。窗外月光仅是微弱的蓝色环境光，不投射阴影。" |
| 边牧变哈士奇/狼 | 黑白狗默认画成 husky | 追加："狗的具体品种：边境牧羊犬。中型犬。耳朵半立。白色从嘴延伸到额头形成白线。不是哈士奇。" |
| 绝区零变美漫 | 粗轮廓被理解成 DC/Marvel | 追加："日本动画的人物造型比例，不是美式超级英雄漫画。人物身材是正常亚洲人体型。" |
| 绝区零变普通日漫 | 多层阴影被忽略 | 追加："阴影不是渐变！阴影是有明确边界的色块。亮部-中间调-暗部之间是硬边过渡。这是插画，不是动画。" |
| 雨雾之都角色太写实 | 2.5D 被理解成全写实 | 追加："角色脸部必须是二次元动漫风格——大眼、小鼻、柔和面部轮廓。只有环境是写实的。" |
| 吉他玫瑰消失 | 细节太小被忽略 | 不强求。若非常在意，追加："吉他音孔周围可以看到暗红色的玫瑰花纹。" |
| 郁金香消失 | 窗台元素被省略 | 追加："窗台上必须有郁金香花盆。橘粉色花朵。这是重要的前景元素。" |

# 附录 B：三种风格速查

| 维度 | 日漫风 | 雨雾之都风 | 绝区零风 |
|------|--------|-----------|---------|
| 轮廓线 | 柔和、水彩感 | 自然过渡、不太强调 | 粗犷有力、笔触感 |
| 阴影 | 柔渐变 | 写实 AO 渐变 | 2-3 层明确分界 + rim light |
| 色彩 | 温暖通透、中饱和 | 克制灰调、低饱和 | 高饱和撞色、浓烈 |
| 光感 | Bloom 柔光过曝 | Diffuse 散射光 | 锐利明暗交界 |
| 氛围 | 宁静呼吸感 | 湿润空气感 | 力量感、像专辑封面 |
| 白天天空 | 蓝天+蓬松白云 | 淡蓝灰+均匀薄云 | 浓郁蓝+形状化云 |
| 夜晚窗外 | 晴朗星空+满月 | 雨夜+雨丝+无月 | 墨蓝夜空+大亮星+锐利月光 |
